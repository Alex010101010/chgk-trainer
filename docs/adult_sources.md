# Источники Чёрного ЧГК

Поиск 14.11.2026. Основной источник корпуса — gotquestions.online. Ниже публичные пакеты, отдельно от анонсов, по которым тексты ещё не подтверждены. По решению игрока возраст пакета для Чёрного ЧГК не ограничен. Десятилетний горизонт действует только для обычной «Классики»; «Бинго» и прежний набор «Своей игры» тоже исключения.

## Кубки Ржевского

Игрок 14.11.2026 прямо отнёс серию к 18+: название серии — самостоятельное основание классификации, независимо от флага сайта. В проверенном каталоге 369 пакетов таких названий нет.

Найден [полный 4-й Кубок Ржевского, Саранск, 2001](https://chgk1.narod.ru/questi/samara/4rzhevsk.htm). Возраст не мешает включению в отдельный взрослый набор; перед импортом проверить формат и пригодность вопросов. В обычную «Классику» не включать.

Упоминание Ржевского внутри отдельного вопроса обычного турнира само по себе не делает весь пакет взрослым.

## ДинаБанк

Публичный адрес: https://dinabank.livejournal.com/ . Страница прочитана прямым HTTP-запросом 14.11.2026. Это каталог раздач: правила предлагают заполнить форму в записи, после чего пакет высылается на email; заявки просматриваются вручную. Есть метки «тематические турниры: Кубок Ржевского» и «синхроны: Весенний ржевский асинхрон». Это общий источник пакетов, а не возрастная категория — каждый пакет проверять отдельно. Формы не отправлялись.

Игрок дал пример письма из Gmail с меткой Dina как образец доставки обычного пакета, затем решил, что для поиска по публичному каталогу письмо читать не нужно. Gmail не подключаем ради этого письма. Содержание письма и вложения не прочитаны. Условия проекта на публичной странице: некоммерческое использование; получение пакета не доказывает разрешение на его публичное распространение в приложении.
