# Отбор вопросов

Согласовано с игроком 14.11.2026.

## Обычная «Классика» и вопрос дня

Первый отыгрыш пакета — в пределах последних десяти лет, без будущих дат. Дата публикации и дата загрузки возраст не определяют. Без подтверждённой даты пакет не включается. Учебные примеры не дают исключения из возраста: устаревшие примеры заменяются свежими.

В сборку берутся 300 наиболее новых проверенных обычных пакетов из доступного каталога. Это отбор среди уже известных скачанных турниров, а не гарантия полного обхода всего сайта. В игре случайный выбор тоже предпочитает новые: вес равен `1 / (1 + возраст_в_годах)`. Повторение промахов и слот приёма недели сохраняются. На телефоне возраст дополнительно проверяется при выборе вопроса.

## Исключения

- «Бинго» вне ограничения по времени: сохраняется весь учебный корпус.
- «Своя игра» сохраняет прежние 623 темы и прежний отбор. По запросу игрока 16.11.2026 добавлены четыре PDF-пакета «Крафт №12/13»: индивидуальные и командные, 32 темы / 160 вопросов; Затем из архива по ссылке игрока добавлены ещё 143 темы / 715 вопросов (17 документов). Всего 798 тем / 3990 вопросов. Новое десятилетнее ограничение к ней не применяется.
- Чёрное ЧГК не ограничено возрастом; его материалы хранятся отдельно и в обычную игру не попадают. В «Классике» доступен отдельный выбор «Чёрное ЧГК · 18+». При первом входе показывается предупреждение с подтверждением, которое сохраняется на устройстве.

## Определение взрослого пакета

Основания: `adultOnly=true`; явное 18+ в названии/преамбуле; предупреждение автора о взрослом содержании; серия «Кубок Ржевского», которую игрок прямо отнёс к 18+. Флаг `adultOnly=false` не отменяет предупреждение автора: на реальных пакетах он оказался ненадёжным.

Слово «чёрный» и упоминание Ржевского в отдельном вопросе не определяют категорию всего турнира. Непроверенные или неоднозначные метаданные исключаются из обычной выборки до разбора. Для категории сохраняются основание и ссылка на пакет. При чтении HTML выбирается объект именно запрошенного пакета по id: на странице есть и чужие пакеты в рекомендациях. Длинная преамбула может храниться отдельной текстовой записью Next.js; её нужно раскрыть перед классификацией.

## Файлы и обновление

`pack_catalog.json` — проверенные даты, категории и выбранные пакеты; `gq_recent_dump.json` — новая обычная выборка; `gq_adult_dump.json` — отдельные сырые взрослые пакеты; `adult_pack_sources.json` — явно найденные источники взрослых пакетов. Прежние сырые дампы остаются архивом.

Подготовка: `python3 scripts/refresh_pack_catalog.py --source data --out /private/tmp/chgk-selection`. Затем проверить разницу с текущим набором и только после этого заменять производные данные. Сборщик приложения кладёт обычную выборку в `questions.json`, а взрослый дамп после той же очистки и проверки пригодности — в отдельный `adult_questions.json`. Пакеты 18+ должны иметь проверенную категорию; сборка останавливается при пересечении ID с обычным ассетом. Из 255 сырых вопросов семи пакетов в текущую взрослую сборку вошло 214; недоступные раздатки и дуплеты исключены. Сырые данные не меняются.

Публичные ссылки, ДинаБанк и кандидаты для пополнения перечислены в [adult_sources.md](adult_sources.md). Запросы пакетов через формы и рассылку не отправлялись.
