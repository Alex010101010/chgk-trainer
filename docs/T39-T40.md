# T-39 — Избранные вопросы
Кнопка сохранения/удаления в разборе Классики (включая 18+), Бинго, вопроса дня, Своей игры, проверки недели и примеров приёма. Список в профиле: новые сохранения первыми, поиск по вопросу, ответу, пояснениям, автору и названию режима/пакета. Открывается полный сохранённый вопрос, раздатка, ответ, зачёт, комментарий, источники и автор; разбор приёма сохраняется отдельно. Карточки фактов вне объёма.

Хранение: новый тип события `favorite` в прежнем JSONL-журнале; снимок вопроса переживает обновление/удаление из ассета. Явное saved=false снимает отметку, последнее действие по questionId побеждает без дублей. Версия схемы не повышается: старые приложения пропускают незнакомый тип. Игровые события и расчёты ответов не меняются. Android сохраняет на диск; web-превью использует прежний журнал в памяти. Картинки — прежний кэш/загрузка HandoutStore.

Проверки: настоящий файл журнала, повторное открытие приложения/хранилища, сохранение и удаление, дубли и повреждённые записи, полный снимок и пояснение; ошибка записи не показывает ложную звезду. Экранный путь от раскрытия вопроса до поиска и просмотра из профиля на реальном вопросе; отсутствие кнопки до раскрытия. Маленький экран с крупным шрифтом.
