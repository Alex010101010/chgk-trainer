# T-38 — Выбор пакета «Своей игры»

Согласовано: сохранить три случайные темы и добавить свободный выбор пакета → варианта → темы. Общего турнирного счёта нет. После темы возвращаться в тот же пакет.

## Как сейчас
`selectSvoyakThemes` в `app/lib/screens/svoyak_screen.dart` выбирает три темы; `_toChoice` возвращает к случайному выбору. `build_svoyak` в `scripts/build_app_assets.py` теряет исходный `packId`, модель `SvoyakTheme` знает только подпись пакета. В базе 814 тем из 38 пакетов, включая 23 ручных. `SvoyakEvent` содержит идентификаторы темы и вопроса; история пригодна для отметок прохождения.

## Решения и шаги
1. Передавать строковый `packId` в ассет и модель. Явный справочник `data/svoyak_packs.json` объединяет проверенные ручные пакеты по турнирам и задаёт варианты. Остальные пакеты доступны под исходными названиями без выдуманного типа. Старый ассет читается с группировкой по подписи. → Проверка: все 38 пакетов доступны, у «Крафта №14» раздельно 6 командных и 10 индивидуальных тем.
2. В текущем экране добавить каталог и переходы назад по уровням, сохранив прежнюю случайную выборку. Последние добавленные ручные пакеты показываются первыми; темы — в исходном порядке. → Проверка: открыть оба варианта, сыграть тему, вернуться в тот же пакет и обратно к случайным темам.
3. Отметки вычислять по уникальным ID отвеченных вопросов текущей темы: ноль — «Не начата», часть — «Сыграно N из 5», все — «Завершена». Учитывать пас и истечение как сыгранный вопрос; повторные ответы не увеличивают количество. Частичная тема начинается заново, это написано на карточке. Полную можно повторить. Историю и очки не менять. → Проверка: повтор одного вопроса, чужие/старые ID, перезапуск с сохранённой историей.
4. Использовать существующие карточки и PlaySurface, без фиксированной высоты текста. → Проверка: длинное название, экран 320×640, шрифт 1,5; живой экранный цикл на реальном ассете и тематические тесты.

## Риски и границы
Название пакета не является надёжным ID: новые данные группируются по packId. Общий турнир и варианты задаются справочником, не распознаются в приложении по тексту. Исторические события считаются только при совпадении темы и существующего ID вопроса. Отметка отражает охват вопросов за всё время, а не победу или один непрерывный раунд. Выход посреди темы сохраняет уже записанные ответы. Новый каталог не меняет алгоритм случайного выбора и формат журнала.
