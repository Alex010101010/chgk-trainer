# ЧГК-тренер — соглашения по главной

Главная: вопрос дня, четыре режима, приём недели. Профиль доступен в верхнем ряду главной, обновление приложения — в шапке профиля; долгий тап по названию открывает диагностику.

Панда `panda_home_v2.png` задаёт стиль главной и восьми игровых реакций: `took`, `almost`, `missed`, `clap`, `thumbs`, `neutral`, `notes`, `sincere`. Все используемые реакции обновлены в T8 16.11.2026, PNG 512×512 с прозрачным фоном; исходные имена сохранены, точки подключения прежние. Промпты — `docs/PANDA_ART_V2.json`. На промахе и при отсутствии серии — поддержка без осуждения. Тёмно-зелёные карточки и матовое золото кнопки заданы локально, для вопроса и «Своей игры» используется локальное матовое оформление `PlaySurface`.

Не задавать фиксированную высоту карточкам с текстом: при узком экране или крупном системном шрифте режимы переходят в одну колонку. Результат вопроса дня читается из существующего журнала, название приёма — через существующий выбор приёма недели.

Шапка: две декоративные мини-панды (`panda_header_stance.png`, `panda_header_dumpling.png`), между ними текст «Панда будет?» с золотым вторым словом. Фигурки исключены из озвучивания, название остаётся текстом и переносится при крупном шрифте. Панды стоят вплотную к названию; профиль остаётся справа в том же ряду. Обновление находится только в профиле.

Цикл вопроса: вопрос и раздатка прокручиваются отдельно от кнопок; ввод версии остаётся в Классике/Бинго/Вопросе дня. Разбор показывает правильный ответ, свою версию и пояснения; окончательную оценку подтверждает игрок.

«Своя игра»: «Прочитал» → 30 секунд на «Знаю!»/«Пас» → ответ. После «Знаю!» только «Взял»/«Не взял», без клавиатуры и матчера. Очки прежние: +номинал/−номинал, пас или истечение — 0; `userAnswer` в новых событиях пустой, старые записи не меняются. T-35: `responseSeconds` отдельно хранит целые секунды от создания контроллера вопроса до «Знаю!», включая чтение; на раскрытии — «Ответил за N с». После нажатия значение фиксируется. Для паса, истечения и старых записей — null. `secondsUsed` сохраняет прежний отсчёт от «Прочитал».

Полоса таймера рисуется по оставшимся секундам без фоновой анимации: её обновляет существующий таймер контроллера. При проверке элементов внутри прокрутки сначала доводить их в видимую область, особенно после закрепления нижних кнопок.

При доступной высоте ниже 350 шапка показывает только время и полосу (ориентир — LayoutBuilder, Scaffold уже убирает отступ клавиатуры из MediaQuery): длинная подпись при крупном шрифте вытесняет закреплённые поле и кнопку на экране 320×640. Проверка сочетает узкий экран, масштаб 1,5 и клавиатуру.

## Разбор gotquestions (T34)

Массивы вопросов и авторов в экранированной строке Next.js читать через `gq_extract`: сначала снять экранирование JS-строки, затем применить JSON-разборщик. Не считать баланс скобок в исходном HTML: скобка в тексте может удалить целый тур. Повреждённые массивы должны давать ошибку с числом неразобранных фрагментов, а не частичный результат без предупреждения.

Инструкцию ведущему в начале вопроса удалять только до парной закрывающей скобки с учётом вложенных скобок (`_host_instruction_end`). Незакрытую инструкцию сохранять в тексте и исключать вопрос с причиной `host_instruction`: угадывание границы может отрезать сам вопрос.

## Политика корпуса (14.11.2026)

Источник правил — `docs/CONTENT_POLICY.md`; найденные взрослые источники — `docs/adult_sources.md`. Обычная «Классика» и вопрос дня: десять лет по первому отыгрышу, новые предпочтительнее. «Бинго» и прежний набор «Своей игры» — исключения; взрослый набор не ограничен возрастом и не попадает в обычный ассет. T-36: главная открывает `ClassicChoiceScreen`; взрослый набор читается только из `adult_questions.json` после подтверждения 18+ (локальный маркер `adult_consent_v1`). Обычный набор выбран первым; предыдущий выбор не запоминается. Для взрослого раунда `adult: true` отключает границу возраста и резерв вопроса дня; события остаются `classic` с тегом `adult`. Сборщик очищает отдельные сырые пакеты тем же санитайзером, без возрастного фильтра; пакеты должны иметь `audience=adult` и `metadataChecked=true`, пересечение ID с обычным ассетом запрещено. До замены данных показывать разницу с текущим набором.

Метаданные читать через `extract_pack(html, pack_id)`, проверяя id запрошенного пакета, и раскрывать ссылки на длинную преамбулу Next.js. На странице есть чужие пакеты в рекомендациях; первый объект `pack` может принадлежать им. `adultOnly=false` не отменяет явное предупреждение 18+ в названии или описании.

## Импорт PDF-пакетов «Своей игры»

Пакеты из PDF и Google Docs добавлять в `data/svoyak_manual.json`, происхождение и контрольные количества — в `data/svoyak_manual_sources.json`; сборщик объединяет их с прежним отбором. Проверять все темы по пять вопросов и номиналы 10–50, дубли и сохранность старых записей. Общие условия темы переносить в текст каждого вопроса. Поля PDF распознавать по меткам: комментарий может стоять перед ответом (Крафт №12, «Дожди», 50). Заголовок десятой темы не считать вопросом за 10. Не выдумывать дату турнира и не записывать редакторов как авторов вопросов.

В архивных документах номер следующего вопроса может быть склеен с URL, ответом или комментарием: сверять полную последовательность 10–50 в каждой теме. Повторы ручных вопросов сравнивать по полному нормализованному тексту без повторяемой вводной темы; `duplicate_key` обрезает текст и может принять разные вопросы с общей вводной за дубли.

T-38: каталог «Своей игры» группирует по `packId`; ручные турниры и варианты задаются в `data/svoyak_packs.json`. Новому импорту достаточно исходного packId для доступности в каталоге; для объединения командного и индивидуального пакетов добавить явную запись в справочник. Прогресс — уникальные существующие ID вопросов из журнала по themeId за всё время; частичная тема при выборе начинается заново.

Экранный прогон с настоящим ассетом: дождаться загрузки изолята через `tester.runAsync`, затем прокручивать и дать кадру перестроиться до тапа. Для снимка `toImage` и `toByteData` выполнять внутри `runAsync`: в искусственных часах теста ожидание растеризации зависает.

T-39: избранное — события `favorite` в существующем журнале, со снимком `Question.toJson()`, источником режима и дополнительным разбором приёма. Последнее действие по questionId побеждает; запись звезды подтверждать только после успешного append, не менять игровые AnswerEvent/SvoyakEvent. Снимок читается без текущего ассета; раздатка использует прежний кэш HandoutStore. Кнопка появляется после раскрытия ответа, список и поиск доступны из профиля. T-40: InstalledVersion читает локальный PackageInfo, не сетевой манифест обновления.

В экранных тестах избранного выбирать первый Scrollable внутри ListView текущего экрана: общий первый/последний Scrollable может принадлежать поиску или SelectableText. Снимок брать с ближайшего RepaintBoundary над текущим Scaffold, а не с первого в дереве: при нескольких маршрутах первый даёт фон скрытого экрана.

Тесты профиля задают локальные метаданные через PackageInfo.setMockInitialValues; перед проверкой реплики панды прокручивают до PandaSays и ждут её задержку. Новые строки сверху меняют видимую область, но не выбор реплики.
